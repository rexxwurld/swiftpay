SwiftPay API Documentation

SwiftPay is a Paystack-style payment infrastructure: onboard customers, assign them dedicated virtual accounts, and get verified webhook-driven wallet credits when they pay by bank transfer — plus payouts, refunds, split payments, subscriptions, and disputes.

Open Interactive API Explorer
All endpoints below live under /api/v1 (use this for new integrations). They're also mounted unversioned at /api for back-compat — that alias will eventually be removed, so point new code at /api/v1.

Quick start

1. Register a merchant and save the secretKey from the response.

curl -X POST /api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{"businessName":"Test Store","email":"a@b.com","password":"pass1234"}'

2. Use that key as a bearer token on every authenticated request.

curl /api/v1/wallet \
  -H "Authorization: Bearer sk_test_xxx"

3. Verify payments server-to-server — never trust a browser redirect query on its own. Use GET /payments/verify/{tx_ref} and/or the signed X-SwiftPay-Signature merchant webhook before fulfilling an order.

API reference by area

Auth

Register, login, session, and 2FA (setup/enable/disable/verify).

Merchant

Profile, webhook URL, API key rotation.

Customers

Create and list your end-customers.

Virtual Accounts

Assign a pooled dedicated account to a customer, fetch, or deactivate one.

Checkout & Payments

Hosted checkout: initialize a payment link, verify by tx_ref, poll the public checkout status/complete endpoints.

Wallet & Transactions

Settlement balance per currency, and the full ledger of payment events.

Payouts & Recipients

Send money to a bank account (single or bulk), and save reusable payout destinations.

Refunds

Fully or partially refund a settled transaction.

Subaccounts

Split-payment sub-merchants — route a percentage of an incoming payment automatically, settle their balance out on demand.

Subscriptions

Plans, subscriptions, and the recurring invoices they generate.

Disputes

Chargeback handling — view disputes, submit evidence, ops resolves them won/lost.

Webhooks

How SwiftPay signs and delivers transaction.success events to your registered webhook URL.

Admin & Settlement

Operator-only: account pool provisioning, per-merchant fee overrides, and forcing/inspecting settlement batches.
